Version K — Style Reference

The exact palette, typography, buttons, and components used on version-k.html — which will be used to build the final implementation.

Color

Colorblind-safe and no red anywhere. The teal/green system carries meaning with text and shape, never color alone. The disliked mint #79C6BC was retired for a crisper #4FB3A5; the light hero wash was replaced with a dark overlay.
