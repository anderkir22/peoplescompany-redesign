WCAG Contrast Reference — 7-Color Brand Palette

Every combination below pairs one of the seven brand colors as text over each of the seven as a background. Each pair is auto-graded against its real contrast ratio (1:1 = none, 21:1 = black on white). White text is included on every background. Combinations are split into Passes AA (normal-text safe) and Does not pass AA (below the 4.5:1 line for normal text — a few of these still clear AA for large text, and are marked as such).

Contrast thresholds used
LevelContrast RatioApplies to
AAA7:1 or higherEnhanced — best for body text
AA4.5:1 – 6.99:1Minimum for normal text
AA Large3:1 – 4.49:1Large text only (≥24px, or ≥18.66px bold) & UI components
FailBelow 3:1Not usable for text

Project target: because this site serves many mobile users aged 60+, aim for 6.5:1+ where possible — above the AA minimum for better real-world readability.

How to read a swatch: the large line is display-size text; the small line is body-size text. The badge is the grade at the pair's actual ratio. A ★ marks white text. Large-only pairs appear in the Does not pass AA column with an AA Large badge — they are fine for headings but not body copy.

To change the palette: edit the PALETTE array at the top of the script — everything regrades automatically.
