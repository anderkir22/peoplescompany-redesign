Homepage hero images — note for the developer

These are the four approved photographs for the homepage hero. They are not four design options to choose between: all four go live.

The behavior to build: the homepage shows one hero image per page load, picked at random from these four. That one image is held for the whole visit: the alternates appear only when the page is loaded again. Every visit is a fresh draw, so a returning visitor may see a different photograph than last time, and may see the same one twice in a row.

This page stacks all four so the whole set can be reviewed at once. Everything except the photograph — the copy, the type, the dark overlay gradient, the stat row — is identical on all four and comes straight from the live pc.css rules, so the only variable is the image.
